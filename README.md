## 💻 Ví dụ Code Python

Biến lưu tên sinh viên là `student_name`.

Biến lưu lịch học là `schedule_list`.

```python
def print_schedule(student_name, subjects):
    print(f"Lịch học của {student_name}")

    for subject in subjects:
        print("-", subject)

student_name = "Nguyen Van A"

subjects = [
    "Toán rời rạc",
    "Lập trình Python",
    "Cơ sở dữ liệu"
]

print_schedule(student_name, subjects)

```
